# 部署手册

## 前置条件

- 完成 [迁移手册](MIGRATION.md) 的备份、只读核对和逐应用准备。
- 所有在线实例都能理解 `release_scope` 后，才允许创建白名单发布。
- `TRUST_PROXY_HOPS` 与真实网络拓扑一致；直连部署设为 `0`。
- 设置数据库、OSS、JWT、上传上限、任务轮询和保留期。缺少关键配置时服务拒绝启动。

## 发布步骤

1. `PUBLISH_TASKS_PAUSED=true` 部署兼容版本，执行健康检查和旧契约回归。
2. 确认应用结构为 `ready`，版本 ID 水位正确。
3. 设为 `PUBLISH_TASKS_PAUSED=false` 并滚动重启。
4. 创建一个禁用草稿，发布后确认版本、任务和审计同事务存在。
5. 启用小范围白名单，核对精确平台 userId、任务日志和客户端实际加载上报。
6. 按应用逐步扩大；不要同时对所有应用切换。

## 观测

区分扫描上下文数、适用数、更新发送尝试、撤销发送尝试、即时错误和客户端安装成功上报。旧客户端没有 OTA 接收 ACK，不能把发送尝试展示为接收人数。

任务 `succeeded` 只表示本轮服务端分发完成；离线客户端在重新订阅时补发当前适用版本。

## 故障开关

`PUBLISH_TASKS_PAUSED=true` 会暂停任务领取，但不会放宽资格筛选。HTTP 检查、普通消息和已有订阅状态仍工作。故障时优先暂停任务，绝不能恢复全应用无条件广播。
