# 当前进度（2026-10-23）

本次交付改为全新安装基线。旧计划的迁移、兼容工作已取消，原完成率不再适用，不将“删除已取消需求”计成全项目 100%。

## 已实现

- 新版 App/Manage 路由、规范检查更新字段与 Socket 应用协议；无旧检查入口或旧响应别名。
- 规范字段 SQL 仓储和应用分表；无旧列双写、历史回填、读取切换及旧升级链。
- db:init 新服务器空库初始化、目标确认及幂等重试。
- 永久/有期限 Key、显式多应用授权、四种权限预设；CLI 预建应用表，无登录/管理员表。
- 发布/名单/任务/审计事务、目录一致快照、幂等上报与 SHA-256 错误元组聚合。
- 外部后台统计/明细/执行记录/审计查询、应用隔离及撤销校验。
- 任务/执行记录/审计永久保存；保留消息 TTL 查询删除、匹配 ACK 删除和同目标覆盖。
- 测试集中在 test/；更新了现代业务测试并移除旧协议/迁移专用测试。

## 验证

新服务器部署简化后的验证通过：类型检查、lint、生产构建，以及隔离 MySQL 全量回归（41 个套件、315 项测试，无跳过）。测试仅使用独立临时 MySQL，不连接项目 .env 中导入旧数据的库；CLI 子进程显式使用不存在的配置文件和专用测试账号。

测试数量与旧批次不可直接比较：已取消的旧接口、旧口令、历史回填和旧数据库升级及旧库保护专用测试已移除，现代发布事务、审计回滚、任务租约、授权、HTTP/Socket 和数据类型回归保留。
