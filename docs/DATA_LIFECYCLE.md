# 数据生命周期

## 永久记录与查询范围

发布、安装报告、错误组、任务、执行记录、应用审计及全局运维审计持久化到 MySQL，不按时间自动删除，也没有保留天数配置。撤销 Key 不删除凭证及审计记录。

查询默认最近 30 天、单次跨度最多 90 天，每页最多 100 条。这是资源限制，不是保存期限；可以指定任意已有记录的时间段并分段读取。任务/审计响应通过 retention=permanent 声明保存语义。全局 audit list CLI 当前只返回默认窗口的第一页。

## 自动处理

| 对象 | 行为 |
| --- | --- |
| 用户/设备待确认消息 | 默认 24 小时有效；补发查询发现过期则删除，匹配 ACK 删除，同目标后续消息覆盖当前消息 |
| API Key | 永久 Key 不到期；设置 expiresAt 的 Key 到期失效，撤销后后续认证失败，记录不删除 |
| 发布目录缓存 | 5 秒有效，后续读取刷新；策略写入主动失效 |
| 连接与订阅 | 取消订阅或断线后释放进程内状态 |
| 任务租约 | 轮询发现过期后记录 lease_expired 并尝试接管，保留每次执行记录 |
| 名单 | 显式替换或变更范围时在事务中更新，记录完整分段差异审计 |

MESSAGE_RESEND_TTL_SECONDS 控制待确认消息有效期。过期删除发生在读取时，不运行后台批量清理；未被读取的过期行可以留在表内，但不会被补发。

Worker 随服务启动运行，PUBLISH_TASK_POLL_MS 控制轮询间隔。运维期间停止全部服务实例，防止后台继续写入。

## 外部系统与运行日志

本项目没有定时删除 OSS 资源或孤立对象的任务。数据库 Event、OSS Bucket 生命周期、主机脚本和日志轮转由部署方管理，需独立核对。

服务运行日志写标准输出或 PM2 日志文件，尚无持久化查询/告警后端。业务日志 API 查询的是数据库中的任务执行记录、应用审计和客户端错误，不读取任意服务器文件。

## 消息权限

管理消息接口按 API Key 的显式应用授权和 messages:send/messages:read 权限校验。TRUST_PROXY_HOPS 与来源 IP 解析用于上报/审计来源记录，不代替凭证认证或应用隔离。
