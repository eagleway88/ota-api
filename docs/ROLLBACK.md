# 回滚指南

回滚目标必须支持当前数据库结构、App/Manage 协议、API Key、发布范围、任务租约和消息模型。部署前在独立数据库副本上验证目标版本。

1. 关闭入口并停止全部服务实例，确认在途事务和任务执行状态。
2. 保存当前数据库、资源引用、配置与服务版本快照，并验证备份可恢复。
3. 部署已验证的目标版本，核对当前发布策略和任务状态。
4. 不重编号发布序号，不降低自增水位，不覆盖已发布资源 URL。
5. 验证 HTTP、Socket、任务恢复和应用隔离后恢复入口。

数据库 down 不自动删除结构。重装时创建独立空库并初始化，现有数据由运维另行归档。恢复数据库备份、服务版本及调用方配置时，应将它们作为一致的部署单元验证。
