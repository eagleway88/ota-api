# 回滚边界

新版数据库与协议不兼容重构前版本。不要将旧二进制连接到新版数据库，也不要将旧 SQL 导入新库。

本版初始化 down 主动拒绝自动删库。需要重装时创建另一个空库并重新初始化；原库由运维单独归档或按明确审批删除，本项目不自动清空。

新版内的回滚只能选择理解当前规范字段、API Key、应用隔离、public/allowlist、任务租约与消息结构的版本。关闭入口并停止全部实例，保存当前数据库备份，先在独立副本验证后再部署。不要重编号已发布序号、覆盖包 URL 或降低序号水位。

如果必须恢复旧系统，应使用其独立旧数据库/备份、旧配置与匹配客户端，作为整套独立系统恢复；这不是新版数据库的自动反向迁移。维护期间没有 Worker 暂停变量，必须停服务。
