# 兼容层清理清单

只有同时满足以下条件，才能移除 `src/compat/legacy/`：

1. 入口计数、SDK 清单和业务方共同确认旧 HTTP、旧 Socket.IO 和旧管理调用已经退出；短期无请求不足以证明离线客户端退出。
2. 所有应用结构为正式版本，历史正式字段回填与影子读取对账完成，旧列双写回滚窗口结束。
3. 正式 v2 接口、任务恢复、消息和上报回归通过。
4. 正式模块不再导入兼容目录，根模块可移除唯一的 `LegacyCompatibilityModule` 注册。

清理顺序：先停入口、再停旧列双写、移除模块注册和兼容目录，最后通过单独受控迁移删除无依赖旧列。已经执行的迁移历史不得删除或重写。
