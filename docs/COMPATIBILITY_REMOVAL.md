# 兼容层清理清单

2026-10-22：兼容承诺仅保留旧版 `POST /api/version/check`。上传、发布、上报、消息、订阅与管理调用方随本版更新用法，无须等到全部旧管理调用自然退出才替换接口。

当前版本模块只注册 `check`，旧创建、上传、列表和三个上报路径返回 `404`。新版通过 v2 文件/草稿/发布及上报接口工作。原写入实现已移至 `compat/legacy/tests/fixtures/`，只供历史迁移测试，禁止注册为运行时 Provider。管理员与消息模块目前仍位于旧目录，但由根模块直接装配，目录清理继续按职责推进，不承诺其旧协议。

检查适配层与历史存储适配层分别清理：

1. 旧检查入口继续保留并运行契约回归，直到另行决定结束支持；其他旧协议不构成保留条件。
2. 所有应用结构为正式版本，历史正式字段回填与影子读取对账完成，旧列双写回滚窗口结束。
3. 正式 v2 接口、任务恢复、消息和上报回归通过。
4. 正式模块不再导入旧协议实现；`LegacyCompatibilityModule` 仅装配检查模块，不能重新混入发布、上传或上报。

停止旧写入口不会自动迁移旧数据。先完成正式字段回填与对账，再根据检查出口和回滚窗口实际需要停止双写、受控清理旧列；仍需还原旧检查内容的映射继续保留。已经执行的迁移历史不得删除或重写。
