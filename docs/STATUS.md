# 项目状态

## 已实现

- App / Manage 接口、严格 DTO 与 Socket 应用订阅协议。
- 数据库初始化、应用分表准备、release / release_sequence 发布存储；应用发布序号从 1 开始。
- releaseId 标识发布，baseVersionCodes 声明热更新适用范围。
- 多应用 API Key、四种权限预设、到期/撤销及 CLI 运维；同一 Key 可追加/移除应用授权，含事务审计、并发控制与即时校验。
- 发布/名单/任务/审计事务、目录一致快照与更新决策。
- Worker 租约、checkpoint、接管、重试与聚合进度。
- 幂等安装报告、SHA-256 错误分组、统计/任务日志/应用审计查询。
- 永久任务与审计、待确认消息 TTL/补发/ACK。
- OSS 明确配置、UUID 对象名、可选下载域名与错误返回。
- 测试集中在 test/，部署产物不包含测试或 CLI。

## 验证

类型检查、lint、生产构建及全量测试通过：42 个套件、348 项测试，无跳过。测试使用独立临时 MySQL；HTTP 监听回环随机端口；CLI 子进程使用专用测试账号与测试配置，不访问项目 .env。

真实 OSS、外部客户端、部署主机、目标 MySQL 版本及生产容量需要单独验收。单元测试中的 OSS SDK 使用替身，不能等同于实际上传成功。

## 待办

文件失败补偿审计、全局审计 CLI 时间筛选/分页、运行日志查询/告警后端，以及真实环境联调与容量验证仍待完成。见 [开发路线](../ROADMAP.md) 与 [部署指南](DEPLOYMENT.md)。
